# ИИ-ассистент для управления задачами

Telegram-бот для тайм-менеджмента с интеграцией Google Calendar и YouGile.

## Стек
- Python 3.10+, aiogram 3.x
- Google Gemini (NLP)
- PostgreSQL + SQLAlchemy 2.0
- Google Calendar API (OAuth2)
- YouGile API

## Запуск
```bash
cp .env.example .env
pip install -r requirements.txt
python main.py
```
